# terminaltings
This is Nosa's repo of config files and agent stuff.

## Config files
Configs are to be installed and configured appropriately on their respective machines. 

### Global configs
.gitconfig is the only one of these. 

## Agentshi
`agentshi/AGENTS.md` is the source for my global instructions, and
`agentshi/skills` contains my global skills. Install them on every machine with
`python scripts/install.py` (`python3` on Linux). Run the installer again after
pulling changes; keep machine-specific settings and credentials outside the repo.
